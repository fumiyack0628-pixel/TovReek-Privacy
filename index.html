隱私權政策

Privacy Policy

最後更新日期：2026 年 11 月 3 日

1. 簡介

TovReek VCM-01（以下簡稱「本工具」）是一款短影音數據管理工具， 協助創作者透過 TikTok 授權登入，取得帳號及影片相關資料， 用於數據紀錄、歷史追蹤與成效分析。

TovReek VCM-01 ("the Tool") is a short-form video data management tool that helps creators access authorized TikTok account and video information for data recording, historical tracking, and performance analysis.

2. 資料收集範圍

在使用者授權的範圍內，本工具可能取得以下資料：

  • TikTok 公開個人資料，例如使用者名稱及個人檔案資訊。
  • 帳號統計資料，例如粉絲數及影片數量（依 API 權限提供情況而定）。
  • 影片資料，例如影片描述、發布時間、影片長度、觀看數、留言數及分享數。
  • 使用者自行輸入的補充紀錄，例如收藏數。

With user authorization, the Tool may access:

  • Public profile information, such as username and profile details.
  • Account statistics, such as follower and video counts, where available.
  • Video information, including descriptions, publication dates, duration, view counts, comment counts, and share counts.
  • Additional records manually entered by users, such as favorite counts.

3. 資料使用目的

取得的資料僅用於以下目的：

  • 同步及管理 TikTok 帳號與影片資料。
  • 建立歷史數據紀錄及追蹤數據變化。
  • 提供影片成效分析與數據視覺化。
  • 支援使用者自行匯出資料。

Collected data is used to:

  • Synchronize and manage TikTok account and video information.
  • Maintain historical records and track changes over time.
  • Provide performance analysis and data visualization.
  • Allow users to export their own data.

4. 資料儲存與安全

本工具目前採用本機應用程式架構，資料預計儲存在使用者自己的裝置上， 並透過本機資料庫進行管理。本工具並非雲端資料儲存服務。 使用者應妥善保管自己的裝置及相關授權憑證。

The Tool currently uses a local application architecture. Data is intended to be stored and managed on the user's own device through a local database. The Tool is not a cloud storage service. Users are responsible for protecting their devices and authorization credentials.

5. 第三方服務

本工具使用 TikTok 提供的 API 及授權機制，取得使用者同意存取的資料。 TikTok 對其平台及 API 資料的處理，仍受 TikTok 自身的隱私權政策約束。

本工具不會主動販售使用者的個人資料。 若使用者自行匯出或分享資料，應自行確認分享對象及範圍。

The Tool uses TikTok APIs and authorization mechanisms to access data with the user's consent. TikTok's handling of platform and API data remains subject to TikTok's own Privacy Policy.

The Tool does not intentionally sell users' personal data. Users are responsible for determining the recipients and scope when exporting or sharing their data.

6. 授權撤銷與資料刪除

使用者可以透過 TikTok 帳號設定管理或撤銷已授予第三方應用程式的權限。 使用者亦可透過本機應用程式的資料管理方式， 刪除儲存於裝置上的資料（如相關功能已提供）。

Users may manage or revoke third-party application permissions through their TikTok account settings. Users may also delete locally stored data through the Tool's data management functions, where available.

7. 政策更新

本隱私權政策可能因功能或服務調整而更新。 更新後的版本將發布於本頁面。

This Privacy Policy may be updated when the Tool's features or services change. Updated versions will be published on this page.
